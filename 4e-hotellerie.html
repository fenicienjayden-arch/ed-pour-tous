🍳 4e HÔTELLERIE

Restaurant - Service

1. Dresser une Table

Assiette, fourchette à gauche, couteau à droite, verre en haut, serviette. Propre, aligné.
Exercice : Dresse une table pour 2 personnes.

2. Servir le Client

Bonjour, sourire, proposer le menu, servir par la droite, ne jamais mettre le doigt dans l'assiette.
Exercice : Un client arrive, que fais-tu en premier ?

3. Le Menu

Entrée, plat, dessert. Écrire les plats du jour, les prix. Le menu doit être clair.
Exercice : Fais le menu de ton restaurant pour demain.

4. Après le Service

Débarrasser, laver, ranger, nettoyer la table pour le prochain client.
Exercice : Que fais-tu après qu'un client part ?
