🏨 4e HÔTELLERIE

Service - Chambre

1. Dresser une Table

Ordre : Nappe, Assiette au centre, Fourchette à gauche, Couteau à droite, Verre en haut à droite, Serviette sur l'assiette.
La table doit être propre et droite. Le client mange d'abord avec les yeux.
📝 Exercice : Dessine une table dressée et nomme chaque élément.

2. Servir le Client

Étapes : 1. Apporter le menu, 2. Prendre la commande, 3. Servir à droite du client, 4. Débarrasser à gauche, 5. Dire "Merci, à bientôt".
On ne court pas dans la salle, on ne crie pas.
📝 Exercice : Cite les 5 étapes du service.

3. Faire une Chambre d'Hôtel

Étapes : 1. Aérer, 2. Changer les draps, 3. Nettoyer la salle de bain, 4. Vérifier les serviettes, 5. Vérifier que tout marche (lampe, télé).
Une chambre sale = client qui ne revient plus.
📝 Exercice : Cite les 5 étapes pour faire une chambre.

4. Le Petit Déjeuner

Petit déjeuner à Bunia : Pain, Beurre, Oeufs, Thé, Café, Jus. On prépare tout avant que le client se lève. Le thé doit être chaud, le pain doit être frais.
📝 Exercice : Compose un petit déjeuner pour 2 personnes.
