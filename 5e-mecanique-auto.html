🚗 5e MÉCANIQUE AUTO

Électricité Auto et Diagnostic

1. Électricité Auto

Batterie 12V, alternateur recharge, démarreur lance le moteur, phares éclairent.
Exercice : C'est quoi l'alternateur ?

2. Le Démarreur

Petit moteur qui lance le gros moteur. Si tu entends "clic clic" mais ça ne démarre pas, c'est souvent le démarreur ou la batterie.
Exercice : Tu entends clic clic, c'est quoi le problème ?

3. Diagnostic Voiture

1. Écouter le client 2. Écouter le bruit 3. Regarder sous le capot 4. Tester sur route.
Exercice : Cite les 4 étapes du diagnostic.

4. Boîte de Vitesse

Manuelle = on change avec la main. Automatique = la voiture change seule. Embrayage = pour passer les vitesses.
Exercice : Manuelle ou automatique, quelle différence ?
