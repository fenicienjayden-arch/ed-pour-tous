🌾 3e AGRICULTURE

Planter

1. Le Manioc

Planter les boutures, 1 mètre entre les plants, récolte après 9-12 mois. Le manioc nourrit toute la famille.
Exercice : Combien de temps pour récolter le manioc ?

2. Le Maïs

Semer 2-3 graines par trou, 75 cm entre les lignes, sarcler 2 fois.
Exercice : Combien de graines par trou pour le maïs ?

3. Le Haricot

Riche en protéines, se vend bien au marché. Ne pas planter dans l'eau qui stagne.
Exercice : Pourquoi le haricot est bon pour la santé ?

4. Sarcler et Fumier

Sarcler = enlever les mauvaises herbes. Fumier = caca de poule / chèvre, c'est l'engrais gratuit.
Exercice : C'est quoi le fumier ?
