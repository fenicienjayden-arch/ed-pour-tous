⚡ 3e ÉLECTRICITÉ

Installation Maison

1. La Prise

La prise donne le courant. Ne jamais mettre les doigts dedans. Si la prise chauffe, elle est dangereuse.
Exercice : Ta prise chauffe, que fais-tu ?

2. L'Interrupteur

Allume / éteint la lampe. On branche l'interrupteur sur le fil de phase.
Exercice : C'est quoi un interrupteur ?

3. Le Disjoncteur

Il coupe le courant quand il y a un problème. C'est le gardien de la maison.
Exercice : Pourquoi le disjoncteur saute ?

4. Installer une Lampe

Couper le courant, brancher les fils, fixer la lampe, tester.
Exercice : Cite les étapes pour installer une lampe.
