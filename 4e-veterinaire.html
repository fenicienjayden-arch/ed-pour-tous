🐄 4e VÉTÉRINAIRE

Maladies - Vaccins

1. Animal Malade

Ne mange plus, ne bouge plus, fièvre, diarrhée. Isoler l'animal malade pour ne pas contaminer les autres.
Exercice : Comment reconnaître un animal malade ?

2. Les Vaccins

Vaccin = protège l'animal. Poule, chèvre, chien = tous doivent être vaccinés. Garder le carnet.
Exercice : Pourquoi vacciner les animaux ?

3. Les Parasites

Vers, tiques, puces. Ils sucent le sang. Nettoyer la maison, donner le vermifuge.
Exercice : C'est quoi un parasite ?

4. L'Hygiène

Nettoyer chaque jour, eau propre, nourriture propre. Mains propres avant et après toucher les animaux.
Exercice : Cite 3 règles d'hygiène en élevage.
