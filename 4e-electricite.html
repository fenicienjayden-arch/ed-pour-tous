⚡ 4e ÉLECTRICITÉ

Installation Maison

1. Le Plan d'Installation

Avant de tirer les fils, on dessine : où sont les lampes, les prises, les interrupteurs. Sans plan, on se perd.
Exercice : Dessine le plan électrique de ta chambre.

2. Les Fils - Couleurs

Rouge / Marron = Phase (le courant arrive). Bleu = Neutre (le courant repart). Vert-Jaune = Terre (protection). Ne jamais confondre.
Exercice : Quelle couleur pour la terre ? Pour la phase ?

3. Installer une Lampe + Interrupteur

Phase -> Interrupteur -> Lampe -> Neutre. L'interrupteur coupe toujours la phase, jamais le neutre.
Exercice : Pourquoi l'interrupteur coupe la phase ?

4. Installer une Prise

Phase + Neutre + Terre. On serre bien les vis, un fil mal serré chauffe et brûle.
Exercice : Pourquoi un fil mal serré est dangereux ?
