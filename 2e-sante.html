🩺 2e SANTÉ

Le Corps - Hygiène

1. Le Corps

Tête, bras, jambes, ventre. Le corps doit être propre et nourri pour être fort.

Exercice : Nomme 5 parties du corps.

2. L'Hygiène

Se laver les mains, se brosser les dents, se laver le corps. Mains sales = maladies.

Exercice : Quand faut-il se laver les mains ?

3. L'Eau Propre

Boire de l'eau propre. Eau sale = diarrhée, choléra. Bouillir l'eau pour la rendre propre.

Exercice : Comment rendre l'eau propre ?

4. L'Infirmier

Il soigne, écoute, aide le malade. Il porte blouse blanche et travaille à l'hôpital.

Exercice : C'est quoi le travail de l'infirmier ?
