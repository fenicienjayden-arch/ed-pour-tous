Ch1: 7ème - 8ème Bases

Fractions: a/b + c/d = (ad+bc)/bd
Puissances: a^m * a^n = a^(m+n) - (a^m)^n = a^(m*n)
Équation: 2x+3=11 => 2x=8 => x=4

Ch2: Factorisation (1ère-3ème)

a²-b²=(a-b)(a+b)
a²+2ab+b²=(a+b)²
a²-2ab+b²=(a-b)²
Exemple: x²-9 = (x-3)(x+3)
Exercice Exetat: Factoriser 4x²-12x+9 = (2x-3)²

Ch3: Trigonométrie (4ème)

sin²+cos²=1 - sin(30°)=1/2 - cos(60°)=1/2 - sin(45°)=√2/2
Dans triangle rectangle: sin=opp/hyp, cos=adj/hyp, tan=opp/adj

Ch4: Limites (5ème)

lim(x→0) sin x / x =1
lim(x→∞) 1/x =0
Si forme 0/0: factoriser ou dériver (règle Hospital)

Ch5: Dérivées (6ème Exetat)

x^n => n*x^(n-1) - sin x => cos x - cos x => -sin x
e^x => e^x - ln x => 1/x
Formule produit: (uv)'=u'v+uv'
Ex: f(x)=x³+2x => f'(x)=3x²+2

Ch6: Intégrales

∫ x^n dx = x^(n+1)/(n+1) + C
∫ e^x dx = e^x + C
∫ 1/x dx = ln|x| + C

Ch7: Exercices Types Exetat

1) Résoudre x²-5x+6=0 => Delta=25-24=1 => x1=2, x2=3
2) Dérivée de (x²+1)(x-2) = 3x²-4x+1
3) lim x→2 (x²-4)/(x-2) = lim x→2 x+2 =4
