💻 5e INFORMATIQUE

Programmation - Réseaux

1. C'est quoi un Algorithme ?

Algorithme = recette de cuisine pour l'ordinateur. Ex : Pour préparer du thé : 1. Faire bouillir l'eau, 2. Mettre le thé, 3. Mettre le sucre, 4. Servir.
L'ordinateur suit les étapes dans l'ordre, sans réfléchir.
📝 Exercice : Écris l'algorithme pour t'habiller le matin.

2. HTML - Créer une Page Web

HTML = langage des sites. <h1> = grand titre, <p> = paragraphe, <img> = image.
Ton site ED POUR TOUS est fait en HTML !
📝 Exercice : Écris en HTML : un titre "Bonjour Bunia" + un paragraphe.

3. Les Réseaux - Wifi, Internet

Réseau = ordinateurs reliés. Routeur = boîte qui donne le Wifi. Mot de passe Wifi = secret, ne jamais le donner à tout le monde sinon ta connexion devient lente.
📝 Exercice : C'est quoi le rôle du routeur ?

4. Maintenance - Réparer un PC

PC lent ? 1. Supprimer les fichiers inutiles, 2. Redémarrer, 3. Vérifier l'antivirus.
PC ne s'allume pas ? Vérifier le câble, la prise, la batterie.
📝 Exercice : Le PC de ton ami est très lent. Que fais-tu en premier ?
