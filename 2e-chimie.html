🧪 2e CHIMIE

Matière - Eau - Air

1. C'est quoi la Matière ?

Tout ce qu'on touche : table, eau, air. Solide, liquide, gaz. La glace fond = solide devient liquide.
Exercice : Classe : pierre, eau, fumée, bois.

2. L'Eau

H2O. Eau propre = vie. Eau sale = maladie. Bouillir l'eau pour la rendre propre.
Exercice : Comment rendre l'eau propre ?

3. L'Air

On respire l'oxygène, on rejette le CO2. Les plantes font l'inverse.
Exercice : C'est quoi l'oxygène ?

4. La Propreté

Se laver, laver les habits, nettoyer la maison. La chimie aide à faire le savon.
Exercice : Comment fait-on le savon ?
