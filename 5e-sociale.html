🧡 5e SOCIALE

Cuisine - Budget

1. La Cuisine

Préparer un repas équilibré : riz + haricot + légumes + fruit. Mains propres, cuisine propre.
Exercice : Propose un menu équilibré pour ta famille.

2. Le Budget Famille

Argent qui entre - argent qui sort. Priorité : nourriture, école, santé, puis le reste.
Exercice : Ta famille a 50000 FC, fais le budget.

3. Le Marché

Comparer les prix, acheter frais, ne pas acheter tout à crédit.
Exercice : Comment bien acheter au marché ?

4. Aider la Communauté

Visiter les malades, aider les vieux, conseiller les mamans. La sociale = aider les autres.
Exercice : Comment aides-tu ton quartier ?
