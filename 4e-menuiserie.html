🪵 4e MENUISERIE

Assemblages - Meubles

1. Les Assemblages

Tenon-Mortaise : Un bout rentre dans un trou. C'est le plus solide.
À mi-bois : On coupe les 2 moitiés et on les croise.
Avec vis + colle : Plus rapide, pour les petits meubles.
📝 Exercice : Dessine un assemblage tenon-mortaise.

2. Fabriquer une Chaise

Étapes : 1. Couper 4 pieds, 2. Couper les traverses, 3. Assembler avec tenon-mortaise, 4. Poncer, 5. Vernir.
La chaise doit être stable : les 4 pieds touchent le sol en même temps.
📝 Exercice : Cite les 5 étapes pour fabriquer une chaise.

3. Le Vernis et la Finition

Ponçage : Papier gros, puis papier fin. On enlève la poussière. On met 2 couches de vernis. La 1ère protège, la 2ème brille.
📝 Exercice : Pourquoi on ponce avant de vernir ?

4. Calculer le Prix d'un Meuble

Prix = Bois + Vis + Colle + Vernis + Main d'oeuvre. Ex: Bois 80000 FC + Autres 20000 FC + Main d'oeuvre 50000 FC = 150000 FC.
📝 Exercice : Bois 60000 + Main d'oeuvre 40000 + Vernis 10000. Total ?
