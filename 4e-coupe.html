✂️ 4e COUPE ET COUTURE

Machine à Coudre, Jupe, Robe

1. La Machine à Coudre

Parties : Aiguille, Canette, Pédale, Volant.
On enfile de haut en bas. On ne met jamais les doigts près de l'aiguille quand on coud. On commence doucement avec la pédale.
📝 Exercice : C'est quoi la canette ?

2. Coudre une Jupe Droite

Étapes : 1. Mesures, 2. Tracer le patron sur papier, 3. Couper le tissu, 4. Coudre les côtés, 5. Ourlet.
Ourlet = on plie le bas 2 fois et on coud, pour que ça ne s'effiloche pas.
📝 Exercice : C'est quoi un ourlet ? Pourquoi on le fait ?

3. Le Patron

Patron = modèle en papier. On le pose sur le tissu, on trace avec la craie en laissant 1,5 cm pour la couture. Si tu oublies la couture, l'habit sera trop petit.
📝 Exercice : Pourquoi on laisse 1,5 cm autour du patron ?

4. Calculer le Prix

Prix = Tissu + Fil + Main d'oeuvre. Ex : Tissu 15000 FC + Fil 2000 FC + Main d'oeuvre 10000 FC = 27000 FC.
📝 Exercice : Tissu 20000 + Main d'oeuvre 15000. Total ?
