💼 Gestion Financière 6e FINAL EXETAT

L1: Diagnostic Financier Ratios EXETAT sort toujours

Ratios structure: Autonomie = Capitaux propres / Total bilan (>0,5 bien). Endettement = Dettes / CP. Liquidité générale = Actif circulant / Dettes CT (>1,5). Rentabilité: ROE = Résultat net / CP, ROA = Résultat / Total actif. Rotation stock = Coût achat / Stock moyen. Délai client = (Clients*360)/CA TTC. Fonds roulement = Ressources stables - Emplois stables. BFR = Stocks + Créances - Dettes non financières. Trésorerie = FR - BFR. EXETAT: calculer FR BFR TN.

🔥 EXETAT 2023: Bilan: Capitaux 50M, Emplois stables 40M => FR =10M. Stocks 8M, Clients 5M, Fourn 6M => BFR=7M => TN=3M.
