Fonction - Électricité

1. Fonction

f(x) = 2x + 1. Si x = 3, f = 7. C'est une machine : tu mets x, ça sort un résultat.
Exercice : f(x)=3x+2, calcule f(4).

2. Électricité

U = R x I. Tension = Résistance x Courant. C'est la loi d'Ohm.
Exercice : R=10, I=2, U = ?

3. La Lumière

La lumière va droit. Miroir = reflète. Lentille = concentre.
Exercice : Pourquoi on se voit dans le miroir ?

4. Logique

Si A est vrai et B est vrai → vrai. Math = réfléchir, pas seulement calculer.
Exercice : Si tous les élèves sont là et Jean est élève, Jean est là ?
