1. Équation 2e Degré

Forme: ax² + bx + c = 0
Discriminant Δ = b² - 4ac
Si Δ>0: 2 solutions x1, x2
Si Δ=0: 1 solution
Si Δ<0: 0 solution
Formule: x = (-b ± √Δ) / 2a

Ex: x²-5x+6=0 => Δ=1 => x1=2, x2=3
