🧪 CHIMIE 4e - pH et Équilibres

CHAP 1: pH - Acide Base
pH = -log[H+] | pH<7 acide, pH=7 neutre, pH>7 basique
Ex: Suc gastrique pH=2 très acide, eau de Javel pH=12 basique
Calcul: [H+]=10^-3 -> pH=3
Neutralisation: Acide + Base -> Sel + Eau
HCl + NaOH -> NaCl + H2O
CHAP 2: Oxydoréduction
Oxydation = perte d'électrons, Réduction = gain
Nombre d'oxydation: Fe passe de 0 à +2 = oxydé
Pile Daniell: Zn + Cu²+ -> Zn²+ + Cu produit électricité
