🍳 5e HÔTELLERIE

Hôtel - Chambre

1. Accueillir à l'Hôtel

Bonjour, enregistrer le client, donner la clé, montrer la chambre.
Exercice : Un client arrive à l'hôtel, que fais-tu ?

2. Faire une Chambre

Lit propre, draps propres, serviettes, savon, balayer, aérer. La chambre doit sentir bon.
Exercice : Liste ce qu'il faut pour faire une chambre.

3. Le Petit Déjeuner

Pain, thé, café, omelette, fruit. Servi à l'heure, chaud.
Exercice : Fais un petit déjeuner pour un client.

4. Gérer un Restaurant

Acheter, calculer le prix, payer, épargner. Prix = nourriture + travail + bénéfice.
Exercice : Calcule le prix d'un plat : riz 3000 FC + viande 5000 FC.
