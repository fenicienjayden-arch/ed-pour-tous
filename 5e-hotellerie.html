🏨 5e HÔTELLERIE

Cuisine - Réception

1. Cuisine Congolaise

Plats : Poulet moambe, Fufu + Sombe, Riz + Poisson, Tilapia grillé.
On goûte toujours avant de servir. Trop de sel = plat gâché. On présente joliment : la sauce à côté, pas par dessus tout.
📝 Exercice : Donne la recette du poulet moambe en 5 étapes.

2. La Réception - Accueillir un Client

Étapes : 1. Bonjour, 2. Demander le nom, 3. Vérifier la réservation, 4. Donner la clé, 5. Montrer la chambre.
On note : Nom, Numéro de téléphone, Nombre de nuits.
📝 Exercice : Un client arrive sans réservation. Que fais-tu ?

3. Gérer les Plaintes

Client fâché ? 1. Écouter sans couper, 2. Dire "Je suis désolé", 3. Proposer une solution, 4. Appeler le chef si besoin.
On ne discute jamais avec un client. On reste calme.
📝 Exercice : Le client dit "Ma chambre est sale". Que réponds-tu ?

4. Calculer une Facture

Facture = Chambre + Repas + Boissons. Ex : Chambre 50000 FC x 2 nuits = 100000 FC + Repas 20000 FC = 120000 FC.
📝 Exercice : Chambre 40000 x 3 nuits + Petit déjeuner 10000. Total ?
