🪵 2e MENUISERIE

Le Bois

1. C'est quoi la Menuiserie ?

Travailler le bois pour faire table, chaise, porte, armoire. Le menuisier construit ce que la famille utilise tous les jours.
Exercice : Cite 3 choses en bois dans ta maison.

2. Les Bois de Bunia

Bois dur = fort, pour table. Bois tendre = facile à couper, pour petit travail. Ne pas couper le bois vert, il va se déformer.
Exercice : C'est quoi le bois dur ?

3. Les Outils

Scie, marteau, mètre, équerre, rabot, ciseau. Chaque outil a sa place, bien rangé après le travail.
Exercice : Cite les outils du menuisier.

4. La Sécurité

Lunettes, pas de mains devant la scie, ne jamais courir dans l'atelier.
Exercice : Que fais-tu avant de scier ?
