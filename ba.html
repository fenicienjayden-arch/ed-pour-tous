Ch1: Pourquoi le Béton Armé ?

Béton seul = fort en compression mais faible en traction (fissure). Acier = fort en traction. On les marie. C'est la base de toute construction à Bunia.

Règle: Béton prend la compression, Acier prend la traction.

Ch2: Matériaux

Béton: C20=20MPa (maison), C25=25MPa (R+1), C30=30MPa (pont). Dosage Bunia: 350kg/m3 = 1 sac 50kg + 2 brouettes sable + 3 brouettes gravier + 30L eau.

Acier: FeE500 (500MPa). HA8, HA10, HA12, HA14. Enrobage à Bunia: 3cm minimum à cause de l'humidité.

fc28 = Résistance à 28 jours | σ_bc = 0.85*fc28/1.5

Ch3: Poutre en Flexion - Calcul Complet

Mu = Moment ultime | As = Mu / (0.9*d*fe/1.15)
EXEMPLE BUNIA: Poutre 20x40cm, portée 5m, charge 12kN/m. Mu=37.5 kN.m. d=36cm. As= 37.5 / (0.9*0.36*434)= 2.66cm² => 3 HA12 (3.39cm²) OK. Cadres HA6 espacés 15cm près appuis, 20cm au milieu.

Ch4: Poteaux

Règle Unibunia: Poteau minimum 20x20 pour 1 niveau, 30x30 pour R+1. Ferraillage: 4HA12 mini, 6HA12 pour R+1.

Poteau 30x30, N=60T: Vérification: Br=27x27=729cm². N adm = 729*(14MPa) = 102T > 60T OK.

Ch5: Dalles

Dalle à Bunia: Hourdis 15cm + dalle compression 5cm = 20cm total. Treillis soudés ST25C + chapeaux HA8.

Épaisseur règle: L/25. Pour L=4m => 16cm mini.

Ch6: Erreurs à Éviter à Bunia

  • Pas assez d'enrobage => rouille
  • Trop d'eau dans béton => fissure
  • Décoffrage trop tôt (<7 jours poteau, <21 jours poutre)
  • Pas de vibration => nids de gravier
