🪵 5e MENUISERIE

Portes, Fenêtres, Armoires

1. Fabriquer une Porte

Mesurer l'ouverture d'abord ! Porte standard : 80cm x 210cm. On fait le cadre, on met les panneaux, on fixe les charnières. La porte doit s'ouvrir sans frotter le sol.
📝 Exercice : Pourquoi on mesure l'ouverture avant de fabriquer ?

2. Fabriquer une Armoire

Étapes : 2 côtés + fond + haut + bas + portes + étagères. On vérifie la diagonale : les 2 diagonales doivent être égales, sinon l'armoire est tordue.
📝 Exercice : Comment vérifier qu'une armoire n'est pas tordue ?

3. Les Machines de l'Atelier

Scie circulaire, Raboteuse, Défonceuse. Elles vont vite, donc danger. On ne travaille jamais fatigué sur une machine. On pousse le bois avec un poussoir, pas avec la main.
📝 Exercice : Cite 2 règles pour travailler avec une machine.

4. Gérer son Atelier

Carnet de commandes : Nom du client, ce qu'il veut, date, prix, avance. On demande toujours une avance de 50% avant de commencer, pour acheter le bois.
📝 Exercice : Pourquoi on demande 50% d'avance ?
